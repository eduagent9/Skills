# Skills

مستودع شخصي لتنظيم المهارات (Agent Skills) وروابط تثبيتها، مستقل عن مشاريع EduAgent وMakhzoni وTatbi9i.

## Design Lab

المصدر الأصلي: https://github.com/0xdesign/design-plugin

لتثبيت المهارة عالمياً على الجهاز باستعمال أداة `skills`:

```bash
npx skills add https://github.com/0xdesign/design-plugin --skill design-lab --global
```

للتحقق من التثبيت:

```bash
npx skills list --global
```

> هذا المستودع يحتفظ بالفهرس والتعليمات فقط، ولا يعيد نشر ملفات المشروع الأصلي. راجع ترخيص المصدر وشروطه قبل النسخ أو إعادة التوزيع.

## ملاحظة Android / Termux

نفّذ أمر التثبيت في Termux على الهاتف؛ إنشاء هذا المستودع لا يثبت المهارة تلقائياً داخل بيئة Termux.
